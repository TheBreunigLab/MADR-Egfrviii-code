# Code associated with Grausam et al.

This repository contains analysis code associated with:

**Grausam K, Pioso M, Sanchez J, et al.  
A syngeneic murine glioma model recapitulates key molecular,
immunologic, and functional features of human glioblastoma
enabling therapeutic development.  
Cancer Research. 2026.**

## Contents

- `single_cell_analysis/` — single-cell RNA-seq analysis

## Data availability

Sequencing data are available through [GEO/SRA accession number when available].

This repository contains code used to generate analyses and figures in the manuscript.
Raw sequencing data are not stored in this repository.


## Usage

Each analysis folder contains scripts and brief instructions describing the order
in which the scripts should be run.
